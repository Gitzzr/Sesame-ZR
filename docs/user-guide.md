## 1. 它能帮你做什么

Sesame-ZR 安装在支付宝里，**自动完成蚂蚁系产品的日常任务**。你只需要在设置里打开对应开关，之后它按你设定的时间表自主运行，并把你关心的结果写进日志与状态栏通知。

## 2. 它**不会**做什么（重要）

这是设计底线，不是「暂未支持」：

- ❌ **不会自动完成、也不会绕过支付宝的安全验证**（滑块、人脸、短信等）。触发验证时模块会**停止发起请求**并提示你人工处理。
- ❌ **不会自动重启应用来「装作」验证通过。**
- ❌ 不会撤回已经发出去的请求 —— 它能控制的是「之后不再发」。
- ⚠️ 因此，**它无法承诺「永不出现验证」**。风控是否触发取决于支付宝，模块能做的是「触发后表现正确」。

## 3. 运行前提

| 项 | 要求 |
| --- | --- |
| 系统 | Android 8.0（API 26）及以上 |
| 框架 | Xposed / LSPosed（**仅支持现代 libxposed API 101+ 入口**，旧的 API 82/100 与 `xposed_init` 已移除） |
| 作用域 | **只勾选支付宝**（`com.eg.android.AlipayGphone`）—— 模块声明的作用域里也只有它 |
| 支付宝版本 | 使用「新接口」需要 v10.3.96.8100 以上 |
| 可选 | root 或 Shizuku（用于执行部分系统命令，如调整后台权限） |
| 可选 | 存储权限（模块要在外部存储里读写配置与日志） |

**激活顺序**：装 APK → 在框架里启用模块并勾选支付宝作用域 → 重启支付宝（或重启设备）→ 打开模块设置页，若主页显示「已激活」即成功。

> 模块主页会显示框架名与版本（`LSPosed` / 其他），以及当前生效的账号。

## 5. 设置项是怎么组织的

理解这四点，看设置页就不会迷路。

### 5.1 三层结构：分组 → 模块 → 设置项

```
分组（页签）        例如：森林 / 庄园 / 海洋 / 运动 / 会员 …
└── 模块            例如：AntForest（蚂蚁森林）、AntFarm（小鸡庄园）
    ├── 【总开关】   每个模块自动带一个「开启XX」开关
    └── 各项设置     开关 / 数字 / 选项 / 好友列表 / 时间表 …
```

- **每个模块都有且只有一个总开关**，名字是「开启」+ 模块名（如「开启森林」「开启庄园」）。**总开关关掉，它下面的所有设置都不生效**，即使子项是开的。
- 模块内的子开关相互独立，可以只开其中几项。

### 5.2 一个关键前提：几乎所有的开关默认都是**关**

全仓库 260 多个设置项里，只有极少数默认开启（例如森林的「平衡网络延迟」「显示背包内容」、农场的「收取七日礼包」、庄园的「庄园签到忽略饲料余量」、以及基础的若干项）。

也就是说：**装上模块后它什么都不会做，直到你手动打开。** 这是有意设计 —— 避免用户装完就被动承担风控风险。

### 5.3 名称里的 `|` 是副标题分隔符

设置项显示为「**主标题 | 副标题**」的形式，例如：

- `收集能量 | 开关`
- `双击卡开关 | 消耗类型`
- `能量雨 | 默认8点10分后执行`

看到 `|` 时，前半是「做什么」，后半是「细节 / 取值说明」。

### 5.4 四种需要说明的输入格式

| 类型 | 格式 | 例子 |
| --- | --- | --- |
| **时间表 / 时间范围** | 逗号分隔的 `HHmm`；范围用 `-`；**`-1` 表示关闭该项** | `0700,0730,1200,1730`；范围 `0700-0730` |
| **好友列表** | 点进去是个可搜索的多选列表，支持全选 / 反选 / 上一个下一个匹配 | 「不收能量 \| 配置列表」 |
| **选择 + 计数** | 先选对象，再给每个对象配一个次数 | 「浇水 \| 好友列表」 + 浇水克数 |
| **毫秒 / 分钟参数** | 绝大多数输入框标注了单位，带「范围」字样的可以直接填 `1000-2000` 表示随机区间 | 「查询间隔(毫秒或毫秒范围)」 |

> 「随机区间」是有价值的：填 `1000-2000` 比固定 `1500` 更像真人操作。

## 6. 全局设置详解

这一组是所有业务共享的基础配置（模块组为「基础」/`BaseModel`）。**调完这些对整体行为影响最大。**

### 6.1 运行节奏

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| **执行间隔(分钟)** | 50 | 每轮任务之间的间隔，范围 1–720。调大更省电 |
| **任务执行轮数** | 1 | 每次调度跑几轮，范围 1–99。源码注释：*「1轮就好，没必要2轮」* —— 调大等于加压力 |
| **定时执行(关闭:-1)** | `0010,0030,0100,0700,0730,1200,1230,1700,1730,2000,2030,2359` | 每天在这些时间点触发执行 |
| **定时唤醒(关闭:-1)** | `0010,0030,0100,0650,2350` | 每天在这些时间点唤醒设备，保证到点能跑 |
| **模块休眠时间(范围\|关闭:-1)** | `0200-0201` | 该时段内不执行；**处于休眠时段时不会写「今日已完成」标记**，所以不会误判为已完成 |
| **只收能量时间(范围\|关闭:-1)** | `0700-0730` | 限定只有该时段收取能量 |
| **定时任务模式** | 系统计时 | 可选「🤖系统计时 / 📦程序计时」 |

### 6.2 稳定性与异常

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| **超时重启** | 开 | 任务超时后自动重启流程 |
| **异常等待时间(分钟)** | 60 | 遇到异常后等待多久再继续 |
| **异常次数阈值** | 8 | 异常累计到该次数后的处理阈值 |
| **开启异常通知** | 关 | 出现异常时发通知 |
| **保持唤醒** | 开 | 保持 CPU 唤醒，保证定时准确 |
| **为目标应用申请后台运行权限** | 开 | 帮支付宝拿到后台运行权限 |
| **手动触发目标应用运行** | 关 | 允许手动唤起支付宝（一般不需要开） |

### 6.3 接口与抓包

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| **使用新接口(最低支持v10.3.96.8100)** | 开 | 关闭则走老版接口（老版支付宝） |
| **开启抓包(基于新接口)** | 关 | 记录接口请求/响应，排查问题时开；**平时开着会明显增加日志量** |
| **启用Hook数据转发** | 关 | 把抓到的数据 POST 到外部地址 |
| **Hook数据转发地址** | `http://127.0.0.1:9527/hook` | 配合 `serve-debug/` 调试台使用 |

### 6.4 显示与日志

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| **全部 \| 记录record日志** | 开 | 业务记录日志 |
| **全部 \| 记录runtime日志** | 关 | 运行时细节日志，量大 |
| **气泡提示 / 气泡前缀 / 气泡纵向偏移** | 开 / 空 / 99 | Toast 提示的位置与内容 |
| **只显示中文并设置时区** | 开 | 简化界面语言并校准时区 |
| **开启状态栏禁删** | 关 | 常驻通知，防被系统清理（提升保活） |

> 日志与配置的落盘位置：`/sdcard/Android/media/com.eg.android.AlipayGphone/sesame-TK/`（下面 `config/` 与 `log/`）。配置**按账号隔离**，每个账号一份 `config_v2.json`。

## 8. 大号 / 小号档位（一键切换）

**一句话**：模块设置页的「扩展&外观」区有一个「账号档位（大号 / 小号）」入口，
点一下就能把当前账号的配置整体切成**大号档**或**小号档**，不用再逐项点开关。

### 8.1 为什么需要它

本模块绝大多数功能都以**好友**为操作对象：收好友能量、一键收取、Pk 榜、浇水、合种浇水、
雇佣小鸡、抢/训练好友、贴罚单、收取好友金币、帮好友抽卡……

如果大号和小号互为好友、又都跑本模块，默认配置会让它们**互相收走对方的资源** ——
最典型的就是小号把大号已经成熟但还没来得及收的能量球偷走。

### 8.2 两套档位分别是什么

| 档位 | 定位 | 会发生什么 |
| --- | --- | --- |
| **大号推荐配置** | 主力号全功能档 | 开启各模块的收益与进度类能力（含面向好友的获取类玩法：收好友能量、一键收取、Pk 榜、领好友礼盒、雇佣小鸡、抢/训练好友、帮抽卡、收好友金币、清理好友海洋…）；保持「丢肥料、请走小摊、通知赶鸡、打赏好友、邀请摆摊」这类**纯干扰项**关闭。若指定了**小号名单**，还会把小号从「不收能量」等排除名单里**移除** —— 因为大号要收小号的能量 |
| **小号推荐配置** | 小号隔离档 | **索取/干扰类**（贴罚单、丢肥料、抢好友、雇佣小鸡…）保持关闭并清空名单；**服务类**（浇水、赠送道具、赠送能量雨、帮喂小鸡、一起拿饲料、送麦子、帮抽卡、送卡片、助力好友）**只对「大号名单」开放**；并把大号写入「不收能量 | 配置列表」，保证不偷大号。若未指定大号名单，则所有跨账号功能保持关闭、名单保持现状（保守） |

两套档位都**不触碰**调度（执行间隔、定时执行、休眠）、日志、气泡提示与各类调优参数 ——
这些与账号间资源无关，一键切换不该打乱你的手感。

### 8.3 小号推荐配置到底关掉了什么

按模块列出（共 79 项跨账号设置，覆盖 16 个模块中全部以好友为对象的开关与名单）。
注意：**服务类名单会在指定了大号名单后被重新指向大号并打开开关**，见 8.5：

- **蚂蚁森林**：收集能量（含收好友）、一键收取、Pk 榜收取、1V1 挑战领奖、领取好友礼盒、炸弹卡、
  1.1 倍能量卡、复活能量；返水归零（浇水 / 赠送道具 / 赠送能量雨的名单改为指向大号）
- **小鸡庄园**：雇佣好友小鸡、打赏好友、一起拿饲料、收麦子、通知赶鸡、家庭；
  清空帮喂小鸡 / 送麦子 / 雇工 / 遣返排除名单
- **蚂蚁新村**：摆摊、贴罚单、丢肥料、邀请摆摊、请走小摊、邀请开通新村；清空对应好友名单与助力名单
- **运动**：抢好友、训练好友；清空抢好友名单
- **神奇海洋**：清理好友海洋；清空清理名单
- **神奇物种**：帮好友抽卡；清空帮抽卡 / 送卡片名单
- **合种**：合种浇水、真爱合种浇水、召唤队友浇水、组队合种克数
- **绿色经营**：收取好友金币
- **蚂蚁农场**：助力好友
- **通用**：双击卡 / 加速器 / 保护罩 / 隐身卡等道具消耗全部关闭

### 8.4 为什么要连「收集能量」一起关

「收集能量」这一个开关在当前实现里**同时门控「收自己」和「收好友」两条路径**，
做不到「只收自己的、不碰好友的」。所以小号档位只能整体关闭它 ——
代价是**小号自己的能量也不会被自动收取**（会自然过期）。

### 8.5 两份「关系名单」：大号名单 / 小号名单

「基础」页签里有两项设置：**大号名单 | 供各功能一键套用**、**小号名单 | 供各功能一键套用**。
它们**不在任务里直接使用**，而是给一键切换当"关系表"用。标记一次，之后一直复用。

各业务模块自己的好友列表一共 **26 项**（浇水给谁、赠送道具给谁、帮喂谁家小鸡……），
按语义分四类，一键套用时**按不同方向处理**：

| 类型 | 数量 | 填进去的含义 | 一键套用时怎么处理 |
| --- | --- | --- | --- |
| 服务类 | 11 | 对这些人做某事，消耗自己、利于对方 | 小号档 → 填**大号名单**并打开对应开关 |
| 索取/干扰类 | 10 | 对这些人做某事，损人利己（贴罚单、丢肥料、抢好友…） | 两档都**清空** —— 即便是对大号做也是净损失 |
| 排除/豁免类 | 4 | 名单内的人**不做**该动作（填人 = 相反效果） | 小号档 → 填**大号名单**（不收能量、不遣返…） |
| 保护改写类 | 1 | 把对方从"被收取对象"改成"被保护对象" | 两档都**不碰**（复活能量是独立体系） |

> ⚠️ 特别注意 **`蚂蚁森林` 里的「小号列表」不是这份「小号名单」**。
> 前者是**复活能量保护名单**（含义是"不偷这些人，反而帮他们护住能量球"），
> 名字里的"周一/小号"是历史遗留。要"不收某人的能量"应该用「不收能量 | 配置列表」。

一键套用会覆盖 **12 个功能名单**：浇水、赠送能量雨、赠送道具、帮喂小鸡、一起拿饲料、送麦子、
帮抽卡、送卡片、助力好友（农场 / 新村）、遣返排除、不收能量。

其中浇水 / 帮喂小鸡 / 送麦子是**「选择 + 计数」**型，一键套用会自动补上**每日 1 次**；
想要更多次数，套用后单独进那个功能改即可。

> 部分名单被独立开关门控（赠送道具、一起拿饲料、送麦子、帮抽卡都有各自开关），
> 一键套用会**连带把开关打开** —— 否则名单填了也不会生效。
> 但**只在大号名单非空时**才这么做；没指定大号就一切保持关闭，避免"看起来配好了其实半开"。

### 8.6 批量启用功能：选中某个账号后勾选它要启用哪些功能

> **先分清两件事**（这一节最容易误解）：
>
> | | 在哪里做 | 做什么 |
> | --- | --- | --- |
> | **批量启用功能** | 本条流程（档位切换里） | 把某个账号加入各功能的**好友列表**，并打开对应开关。**一次搞定 26 个功能，不用逐个进去勾人** |
> | **具体参数配置** | 各模块的**账号配置**里 | 浇水克数、执行时间、次数、阈值…… |
>
> 举例：**浇水**。本流程负责的是「把大号加进『浇水 | 好友列表』并打开浇水」，
> 从此浇水**不必再进那个好友列表逐个勾人**；而**浇水克数（10/18/33/66 克）**、其他细节
> 仍然在「蚂蚁森林」的账号配置里改。本流程**不会**改动那些参数。

名单页是**两级**的：

**一级**（好友列表）：每行 = 左侧勾选框（是否列入这份名单）+ 名称 + 「N 项 ▸」

- 点行的空白处 → 加入 / 移出名单
- 点「N 项 ▸」→ 进入**二级**

**二级**（该账号的功能清单）：完整列出 26 项功能，按四组分节

| 分组 | 默认勾选（大号名单方向） |
| --- | --- |
| 服务 TA —— 消耗自己、利于对方 | ✅ 全勾 |
| 对 TA 索取 / 干扰 —— 损人利己 | ⬜ 不勾 |
| TA 的豁免项 —— 勾上表示「不对 TA 做这件事」 | ✅ 只勾「不收取 TA 的能量」「不遣返 TA 的小鸡」 |
| 独立体系 —— 复活能量保护名单 | ⬜ 不勾 |

**首次进入自动按推荐项勾好**，你只需要改想改的；也有「全选推荐」一键回到推荐。
一级页还有「按推荐重置」可对名单里所有账号一键恢复推荐。

> **勾了才生效，没勾就不动。** 勾选一项功能会同时做两件事：把该账号写进这项功能的名单，
> 并**打开它需要的开关**（比如勾「赠送 TA 道具」会顺带打开「赠送道具」）。
> 反过来，没勾的功能其名单保持空、开关保持关闭 —— 不会被悄悄打开。

> 浇水 / 帮喂小鸡 / 送麦子 是「选择 + 计数」型名单：勾选后会带一个**默认次数 1**，
> 这个次数也属于"具体参数"，同样在账号配置里调整。

> **没勾的功能一律不动**：名单保持你原来的内容、开关保持原状 —— 不会被清空，也不会被打开。
> 需要留意：**浇水 / 帮喂小鸡 / 送卡片 / 助力好友 没有独立开关**（名单里有谁就会对谁执行），
> 所以取消勾选只是"不动它"，**已有名单会继续生效**；要停用请到该功能的账号配置里清空名单。

> **大号档下「豁免项」整组置灰**并在文案里写明原因：大号要收小号的能量，
> 所以「不收取 TA 的能量」对小号没有意义。

### 8.7 操作步骤

1. 打开模块 → 底部「设置」→「扩展&外观」→ **账号档位（大号 / 小号）**
2. 选择要切换档位的账号（条目末尾会显示该账号当前的档位）
3. 选择「**大号推荐配置**」或「**小号推荐配置**」
4. 一级页勾选**名单成员**；对每个要配的账号点「N 项 ▸」进入二级，逐项勾选要**启用**的功能
   （默认已按推荐勾好）。这一步只批量启用功能，**具体参数仍去各模块的账号配置里改**。
   名单成员与功能勾选都会保存，**下次直接复用**
5. 确认页核对汇总（N 个账号、共启用 M 项功能），点「确认应用」
6. 模块立刻落盘并通知支付宝重载配置，Toast 回报**覆盖了多少项、套用了多少处名单**

> ⚠️ 应用档位会**覆盖**你对该档位涉及字段的手工调整（这正是「预设」的语义）。
> 小号档下索取/干扰类的历史名单会被清空。切换前请确认自己接受这一点。

> 💡 **大号和小号分别在两台手机上怎么办？** 那种情况下本机只有你自己一个账号，
> 自动推断不出"谁是大号"。但好友列表是可用的 —— 在第 4 步从好友列表里手动勾选对方即可
> （对方的名字可能带前缀，例如显示成「提醒-\*你的昵称」）。

## 9. 使用建议

1. **先开总开关，再逐项开子开关。** 只开子开关不开总开关不会生效。
2. **不要一次全开。** 第一次使用建议按业务域逐个开启，观察 1–2 天日志与账号状态，再决定是否加下一项。
3. **风控优先看这两处**：运动模块的「运动球任务(开启后有概率出现滑块验证)」、以及任何涉及「一键收取 / 批量 / 改分 / 抽奖」的功能。项目自己的 `CHANGELOG` 也反复提到这些功能默认关闭是有原因的。
4. **别把间隔调得太密。** 默认「执行间隔 50 分钟 + 1 轮」是保守值。把它改成 5 分钟 + 5 轮，等于给账号加压力。
5. **善用休眠时间。** 夜间设成休眠段可以省电，也减少异常唤醒。
6. **调完别急着退出。** Web 设置页的保存走「退出前落盘」，切换页面或直接杀进程可能导致最后一次改动丢失。

## 10. 常见问题

**Q：装好了，主页显示未激活？**
A：三种常见原因 —— ① 框架里没启用模块；② 作用域没勾支付宝；③ 勾了但没重启支付宝。另外模块只支持现代 libxposed 入口，老框架不认。

**Q：总开关开了，但什么都不做？**
A：检查 ① 子开关是否也开了；② 是否在「模块休眠时间」内；③ 「只收能量时间」是否把当前时段排除在外；④ 日志里是否有账号未载入、缺少依赖之类的提示。

**Q：触发了安全验证怎么办？**
A：模块会自动**停止后续请求**并提示你。你需要人工在支付宝里完成验证，然后通过**状态栏通知**或**支付宝主页弹出的确认框**触发恢复。恢复动作会校验账号和一次性令牌，并串行执行。**模块不会自动完成验证，也不会靠重启来绕过。**

**Q：验证完之后还是不动？**
A：恢复会先等旧的业务任务退出再重新开始，这个等待可能有耗时。若长时间不动，看日志确认恢复动作是否真的执行了。

**Q：很耗电 / 发热？**
A：把「执行间隔」调大、「任务执行轮数」保持 1、设置「模块休眠时间」、关掉「保持唤醒」与「开启抓包」。抓包和 runtime 日志是常见的耗电与卡顿来源。

**Q：桌面图标不见了？**
A：检查设置里的「隐藏图标」。这是有意功能，不是被卸载了。

**Q：为什么搜不到某个设置？**
A：全局搜索的匹配范围是**模块名 / 模块代码 / 设置项名称 / 设置项代码 / 描述**。如果搜的是功能的俗称（比如搜「偷能量」而设置项叫「收取能量」），就匹配不到。

**Q：我的配置在哪？换手机怎么迁移？**
A：`/sdcard/Android/media/com.eg.android.AlipayGphone/sesame-TK/config/` 下按账号分目录，把目录整体拷过去即可。旧格式 `config_v2-<userId>.json` 会在首次读取时自动迁移到目录形式。

**Q：想自己看接口抓包？**
A：开「开启抓包」，或直接使用内置的 HTTP 调试接口 `POST /debugHandler`（可转发任意 RPC 方法）。也可以用「扩展功能 → RPC 调试」页面手填方法名与参数。更完整的本地调试台见 `serve-debug/README.MD`。
